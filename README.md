## ✨ Asosiy Imkoniyatlar

- 🧠 **Sun'iy Intellekt**: Gemini API yordamida har bir kino uchun mukammal post matnlarini o'zi shakllantiradi.
- 🎨 **Chiroyli Dizayn**: Premium emojilar yordamida kanalingiz postlarini eng yuqori darajaga olib chiqadi.
- 🗄 **Ma'lumotlar Bazasi**: MySQL orqali kinolar ma'lumotlarini ishonchli va tezkor saqlaydi.
- 👤 **Userbot Integratsiyasi**: Maxsus userbot tizimi bot imkoniyatlarini yanada kengaytirib, avtomatik ishlarni uzluksiz bajaradi.
- ⚡ **Kesh Tizimi**: JSON kesh yordamida tezkor ma'lumotlar almashinuvi.

## 🛠 O'rnatish

Loyihani serverga o'rnatish juda oson. Qadamlarni bajaring:

1. **Repozitoriyni klonlang:**
   ```bash
   git clone https://github.com/meducae/AutomaticPoster-Telegram-.git
   ```

2. **Bazani import qiling:**
   `setup.sql` faylini o'zingizning MySQL bazangizga import qiling.

3. **Sozlamalarni kiriting:**
   `config.php` faylini ochib, kerakli ma'lumotlarni o'zingizga moslab tahrirlang:
   - Telegram Bot Tokeni va Admin ID
   - Kanal username yoki ID (masalan, `@kanal_nomi`)
   - Gemini API Kaliti
   - Ma'lumotlar bazasi (MySQL) login va paroli

4. **Webhook:**
   `set_webhook.php` faylini serverdan ishga tushirib, botingizni webhook'ga ulang.

## 🚀 Ishga Tushirish

Barcha sozlashlar tugagach, userbotni ishga tushiring:
```bash
php userbot.php
```

Bot kanalingiz uchun eng zo'r kontentlarni tayyorlashni boshlaydi! 🎉
